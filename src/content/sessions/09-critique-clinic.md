No submission this week. Week 9's lecture named the grammar of sounding
profound — this session is where that grammar gets pointed at your own work
and asked to justify itself.

## In the session

- everyone brings one paragraph and reads it cold, no framing
- the room asks the single most deflating question it can find
- a running tally of which rhetorical moves survive scrutiny and which
  don't

## Afterwards

Nothing is due, but whatever survives this session is worth carrying into
week 10, where the same test gets run against real philosophy instead of
each other.
